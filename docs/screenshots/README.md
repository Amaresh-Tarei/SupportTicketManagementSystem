# Application Screenshots

This directory contains visual captures of the application in operation:
- `dashboard.png`: Operational Dashboard with status breakdown cards and recent ticket queue
- `ticket-list.png`: Search, filter, sorting, and paginated ticket management table
- `create-ticket.png`: Ticket creation form with business rule validation
- `ticket-details.png`: Full ticket detail view, chronological comment thread, and status transition audit history

To update screenshots, run both backend (`dotnet run`) and frontend (`npm run dev`), then capture the views in your browser.
